# GranaFlow

Aplicativo Android de controle financeiro pessoal, com visual preto e verde.

## Recursos
- Receitas e despesas com armazenamento local
- Categorias, histórico e filtros
- Orçamento mensal e metas de economia
- Relatórios e exportação CSV

## Gerar APK
Cada push executa o workflow **Build Android APK**. Acesse a aba **Actions**, abra a execução concluída e baixe o artefato `GranaFlow-debug-apk`.

## Requisitos
Android 7.0 (API 24) ou superior. Os dados ficam armazenados localmente no aparelho.
