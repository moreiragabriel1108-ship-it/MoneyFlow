# GranaFlow

Aplicativo Android de controle financeiro pessoal, com tema preto e verde.

## Recursos
- Painel com saldo, receitas, despesas e resultado do mês.
- Cadastro, edição e exclusão de lançamentos.
- Categorias e busca de transações.
- Orçamentos por categoria com acompanhamento de limite.
- Metas de economia.
- Filtros de receitas e despesas.
- Exportação de lançamentos em CSV.
- Dados salvos localmente no aparelho.

## Gerar APK
O GitHub Actions gera o APK de depuração a cada push em `main`. Acesse **Actions → Android APK → artefato GranaFlow-debug-apk**.
